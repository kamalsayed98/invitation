# دعوة كتب كتاب كمال ويسرى

صفحة عربية خفيفة، دون تثبيت مكتبات أو خطوة بناء. افتح `index.html` مباشرة، أو شغّل خادم ملفات من مجلد المشروع.

## التعديل

جميع البيانات في `config.js`:

- `groomName` و`brideName`: الاسمان.
- `coupleImage`: مسار الصورة المشتركة؛ الصورة المرفقة محفوظة في `couple.webp` وتُعرض كاملة دون اقتصاص.
- `event`: تاريخ المناسبة ووقتها المحلي والمنطقة الزمنية. تُحسب لحظة الموعد بحسب `Asia/Beirut`، مستقلة عن منطقة جهاز الزائر.
- `locationUrl`: رابط الموقع.


الخطوط العربية تُحمّل من Google Fonts، مع خطوط بديلة محلية عند انقطاع الشبكة. تُستخدم الصورة التي قدّمها صاحب الدعوة. لا توجد موسيقى أو أدوات تتبع.

ملفات التنفيذ: `index.html` للمحتوى، و`style.css` للتنسيق والحركة، و`app.js` للتفاعل والعدّ التنازلي. يستغرق الفتح نحو ٣ ثوانٍ، مع انتقال قصير عند تفعيل تقليل الحركة.

ارتفاع البطاقة المفتوحة ٢٫٨ من ارتفاع الظرف المغلق، وتُوسّط البطاقة نفسها في الشاشة. تظهر الدعوة كاملة دون تمرير داخلي، مع عدّ تنازلي بحجم أصغر وزر موقع الحفل في أسفل البطاقة.

## الرابط العام

[فتح الدعوة](https://kamalsayed98.github.io/invitation/)

تُنشر الصفحة عبر GitHub Pages من الفرع `main` ومجلد الجذر. لا تحتاج الصفحة إلى تثبيت مكتبات أو تشغيل بناء.

الصورة المعروضة بصيغة WebP محسّنة (حوالي ٤٣ كيلوبايت) مع الحفاظ على الأبعاد والشفافية. ملف PNG الأصلي محفوظ.
