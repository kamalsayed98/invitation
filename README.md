# دعوة كتب كتاب كمال ويسرى

[فتح الدعوة](https://kamalsayed98.github.io/invitation/)

## تعديل الدعوة

جميع الأسماء والصور والموعد ورابط الموقع في `config.js`.

- `groomName` و`brideName`: الاسمان.
- `coupleImage`: صورة العروسين المشتركة، بصيغة WebP وشفافية محفوظة.
- `catImage`: صورة القطة. اترك القيمة فارغة لإخفائها.
- `event`: الموعد المحلي والمنطقة الزمنية `Asia/Beirut`، مستقلة عن توقيت الزائر.
- `locationUrl`: رابط موقع الحفل.

المحتوى في `index.html`، والتصميم في `style.css`، والتفاعل والعدّ التنازلي في `app.js`.

## المعاينة محليًا

من مجلد المشروع، دون تثبيت مكتبات:

```sh
python3 scripts/build.py
python3 -m http.server 4173 --bind 127.0.0.1 --directory _site
```

افتح `http://127.0.0.1:4173/`. أعد تشغيل أمر البناء ثم حدّث المتصفح بعد تعديل الملفات. مجلد `_site` مولّد تلقائيًا ولا يُضاف إلى Git.

## رفع التعديلات يدويًا

من Terminal:

```sh
cd /Users/kamal/Desktop/w/invitation-github
git status
git add -A
git commit -m "Update invitation"
git push origin main
```

`commit` يحفظ نسخة محليًا، و`push` يرسلها إلى GitHub. بعد الرفع، يشغّل GitHub Actions البناء والنشر تلقائيًا. راجع التغييرات قبل `git add -A` لأنه يضم جميع تعديلات المشروع.

يمكن أيضًا فتح هذا المجلد في VS Code، ثم من Source Control مراجعة التغييرات، واختيار Stage، وكتابة رسالة Commit، ثم Push أو Sync Changes.

## النشر ومنع استخدام الملفات القديمة

ملف `.github/workflows/pages.yml` ينشر كل تحديث على `main` عبر GitHub Actions. يجب أن يكون Settings → Pages → Source مضبوطًا على **GitHub Actions**، بدل Deploy from a branch.

أثناء البناء، يعطي `scripts/build.py` ملفات التنسيق والبرمجة والصور أسماء تعتمد على محتواها. عندما تتغير صورة أو تنسيقات أو إعدادات الموقع، يتغير عنوان الملف تلقائيًا ويطلبه المتصفح مجددًا. لا تعدّل الملفات الناتجة داخل `_site`.

يبقى HTML نفسه خاضعًا لمدة تخزين GitHub Pages، التي قد تصل إلى عشر دقائق. إذا احتجت مشاركة تحديث فور نشره، أضف إصدارًا جديدًا إلى رابط الدعوة، مثل `https://kamalsayed98.github.io/invitation/?v=20261027`. الصفحة المفتوحة بالفعل تحتاج إعادة فتح أو تحديث؛ لا نعيد تحميلها أثناء قراءتها.

الخطوط العربية من Google Fonts، مع خطوط بديلة محلية. لا توجد موسيقى تلقائية، ولا أدوات تتبع. حركة القطة هادئة وتتوقف عند تفعيل تقليل الحركة.
